Project Overview

This project demonstrates web scraping using Python to extract book information from the Books to Scrape website.

Objective

The objective is to collect book details from a website, organize the extracted information, and explore the data using Python.

Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Visual Studio Code

Website

https://books.toscrape.com/

Project Workflow

1. Import the required Python libraries.
2. Send an HTTP request to the website.
3. Check the HTTP response status code.
4. Parse the webpage using BeautifulSoup.
5. Extract book information.
6. Store the collected data in a Pandas DataFrame.
7. Visualize book ratings using Matplotlib.

Project File

- "Codealpha_WebScraping.ipynb" – Jupyter notebook containing the project code and outputs.

Learning Outcomes

- Understanding HTTP requests and responses.
- Learning HTML parsing with BeautifulSoup.
- Extracting information from web pages.
- Organizing data using Pandas.
- Creating visualizations using Matplotlib.
